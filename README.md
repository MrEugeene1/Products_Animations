# Product Launch Page

An animated, modern product landing page built with pure HTML and CSS.

## Live Feel

This page presents a bold launch experience with:

- A fade-in hero header
- A rotating product image animation
- A hover-reactive call-to-action button
- Sliding feature cards with staggered delays

## Project Preview

The design focuses on clean spacing, high contrast, and motion that draws attention to key product information.

## Tech Stack

- HTML5
- CSS3 (keyframes, transitions, pseudo-classes)
- Vanilla JavaScript (DOMContentLoaded trigger for header animation)

.

## Run Locally

1. Clone or download this project.
2. Open the folder in VS Code.
3. Launch `index.html` in your browser.

Optional: Use the VS Code Live Server extension for fast preview and auto-refresh.

## What You Can Customize

- Update headline text in `index.html`
- Replace the product image URL
- Change accent colors in `styles.css`
- Tune animation speed and delay for different visual styles

## Learning Goals

This project is great for practicing:

- CSS animations with `@keyframes`
- Smooth UI transitions
- Basic landing page layout structure
- Button hover interaction patterns
